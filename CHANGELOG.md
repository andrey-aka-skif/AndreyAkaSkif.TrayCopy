## [0.1.0] - 2026-09-25

### Added

- Иконка в трее вместо главного окна; вторая копия приложения при работающей первой
  сразу завершается.
- Собственная иконка приложения.
- Окно настроек: записи «имя → значение» с проверкой ввода, маской значения и обрезкой
  пробелов по краям, вид уведомления, шифрование значений DPAPI, выход из приложения.
  Открывается кликом с Shift по иконке.
- Повторный запуск приложения открывает окно настроек работающей копии.
- Показ окна настроек при запуске: без записей — до закрытия, с записями — на заданное
  время с отсчётом до скрытия.
- Запуск при входе в Windows; флажок учитывает отключение в Диспетчере задач.
- Клик по иконке копирует текущую запись в буфер обмена так, что она не попадает в
  историю Win+V, облачный буфер и сторонние менеджеры буфера; правый клик выбирает
  следующую запись. Подсказка иконки показывает текущую запись, при пустом списке любой
  клик открывает окно настроек.
- Уведомления о копировании и выборе записи: своим окном или системные.
- Если файл настроек не прочитался, окно настроек называет файл, в который он отложен, и
  открывает его папку.
- Установщик для текущего пользователя, без прав администратора: ярлык в «Пуске» и
  запись в «Установленных приложениях». Запущенное приложение установщик просит закрыть;
  при удалении снимается запуск при входе в Windows, настройки остаются.
